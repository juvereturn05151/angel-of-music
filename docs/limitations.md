# Limitations

- Mock visual analysis does not understand objects, characters, genres, franchises, or artistic intent.
- Mock audio is deterministic functional test audio, not production music.
- Seamless looping is requested but not guaranteed.
- Background jobs do not resume after backend restart.
- No accounts, payments, cloud deployment, Unreal integration, RAG, model training, microservices, or authentication are included.
- No image-rights or music-licensing guarantee is provided.
- No external AI service or local AI model is used in this milestone.
